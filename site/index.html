墨家書櫃 MooFamily Bookshelf

讓讀墨家庭帳號成員，輕鬆瀏覽彼此選擇分享的書籍。

Chrome 擴充功能 手機也能看 安全存取控制 免費開源

這是什麼？

你有沒有遇過這種情況 — 家人買了一本想看的書，結果你也跟著買了一本？ 或是想知道另一半書櫃裡有什麼，卻懶得一本一本問？

墨家書櫃是一個 Chrome 擴充功能，直接在讀墨（Readmoo）網頁裡開啟一個小視窗， 讓家庭帳號的成員可以看到彼此「選擇分享」的書。不用借帳號、不用傳書名，開著就能逛。

放心，所有書籍預設都不公開，要分享哪些書完全由你決定。

功能

家庭書櫃

一眼看到家人分享的藏書，不用借帳號、不用傳書名。

你決定要分享什麼

所有書籍預設不公開，只有你手動開放的書才會出現在家庭書櫃。

資料安全

所有資料透過 HTTPS 安全傳輸，並以認證 Token 控管存取權限。

跨家庭保留設定

離開或更換家庭，你原本的分享偏好不會消失，不用重新設定。

手機也能看

透過手機版網頁瀏覽家庭書櫃，通勤、排隊都能逛。

免費開源

MIT 授權、程式碼公開，不想用預設伺服器還可以自己架。

安裝

Chrome 線上應用程式商店（推薦）

目前還在審核中，通過後會更新連結 — 敬請期待。

我等不及，想要手動安裝
  1. 下載最新版本並解壓縮
  2. 開啟 Chrome，在網址列輸入 chrome://extensions/
  3. 打開右上角的「開發人員模式」
  4. 點擊「載入未封裝項目」，選取剛剛解壓縮的資料夾
  5. 完成！前往讀墨網頁，你會看到「家庭書櫃」按鈕

怎麼使用？

四個步驟就能和家人一起看書櫃。

1

建立家庭

在讀墨網頁點擊「家庭書櫃」按鈕，建立家庭後會拿到一組同步碼。

2

邀請家人

把同步碼傳給家人，對方輸入後就能加入你的家庭。

3

選擇要分享的書

在「個人書櫃管理」裡，逐本切換「開放 / 關閉」，記得按儲存才會同步喔。

4

開逛！

在「家庭書櫃」就能看到所有家人分享的書。手機使用者建議先在電腦版完成一次同步，之後手機網頁就能直接逛。

隱私與安全

你的書單屬於你，不屬於我們。

  • 🔒 安全存取控制 — 所有資料透過 HTTPS 安全傳輸，並以認證 Token 嚴格控管誰能存取你的書單。
  • 🙈 不收集個人資料 — 不需要額外註冊、不記錄 Email、不追蹤你是誰。
  • 🛡️ 預設不公開 — 所有書籍預設都是關閉分享的，你主動開放的書才會出現在家庭書櫃。
  • 🚪 離開家庭即隔離 — 退出家庭後，其他成員立刻看不到你的書；但你原本的分享設定會保留，換家庭不用重設。

完整條款請參閱 隱私政策頁面。

常見問題

別人會看到我不想分享的書嗎？

不會。所有書籍預設不公開，只有你手動選擇「開放」的書才會出現在家庭書櫃。

如果我退出家庭了呢？

退出後對方立刻看不到你的任何資料。你的分享設定會保留，下次加入新家庭時不用重新設定。

最多幾位家庭成員？

基於讀墨的家庭運作方式，最多只能兩人在一個家庭內。與讀墨官方不同的是，退出家庭後沒有 180 天的限制。

可以加入不是讀墨家庭的人嗎？

可以，但只能看到互相開放的書櫃，未來也無法借書給對方。

更改墨家書櫃裡的顯示名稱會影響讀墨官方的設定嗎？

完全不會，墨家書櫃的設定與讀墨官方是分開的，互不影響。

我想自己架後端、或是想貢獻程式碼，該看哪裡？

技術細節、自建後端指南、架構說明都整理在 開發者與技術說明 頁面。
