MooFamily Bookshelf

讓讀墨家庭帳號成員輕鬆瀏覽彼此開放的書籍。隱私優先、開源免費。

Chrome Extension PWA 行動端 E2EE 端對端加密 MIT License

這是什麼？

MooFamily Bookshelf 是一個 Chrome 擴充功能，直接在 讀墨 (Readmoo) 網頁中開啟 Dialog，讓家庭帳號成員可以瀏覽彼此選擇開放的書籍。

你可以決定哪些書要分享給家人看，哪些不要。所有書籍預設不開放，完全由你掌控。

隱私優先

所有書籍預設不開放。你主動選擇要分享的書，儲存後才同步。

端對端加密

資料在瀏覽器中加密後才上傳，伺服器只存密文，開發者無法讀取。

跨家庭保留設定

解綁家庭帳號後，你的開放偏好不會消失。換家庭不用重新設定。

可自建後端

不想用預設伺服器？部署自己的 Cloudflare Worker，完全掌控資料。

使用流程

1

安裝擴充功能

從 Chrome Web Store 安裝 MooFamily Bookshelf。

2

建立或加入家庭

開啟讀墨網頁，點擊「家庭書櫃」按鈕。第一位家人建立家庭取得同步碼，其他人輸入同步碼加入。

3

選擇要開放的書

在「個人書櫃管理」中，逐本切換開放 / 關閉，儲存後才同步。

4

瀏覽家庭書櫃

在「家庭開放書櫃」中看到所有家人選擇分享的書籍。手機上也可以透過 PWA 網頁瀏覽。

家庭帳號是前提 — 此功能需要先建立或加入家庭後才能使用。尚未設定家庭時，Dialog 會引導你完成設定。

技術架構

層級技術說明
前端 Chrome Extension (React + Vite) Content Script 注入 Dialog 至讀墨頁面
行動端 PWA 行動網頁，與 Extension 共用同一後端
後端 Cloudflare Workers Serverless API，可自建部署
儲存 Cloudflare KV 個人開放設定 (per user) + 家庭群組 (per family)
加密 Web Crypto API (AES-256-GCM) 端對端加密，伺服器零知識
資料歸屬設計 — 個人開放設定歸屬個人帳號，不隨家庭綁定 / 解綁而變動。家庭書櫃是動態聚合查詢，不獨立儲存。

自建後端 (BYO Backend)

不想將資料存在本專案預設的伺服器？你可以部署自己的 Cloudflare Worker，完全掌控資料。免費額度即可運行。

  1. Fork 本專案的 worker/ 目錄
  2. 安裝 Wrangler CLI：npm install -g wrangler
  3. 部署至你的 Cloudflare 帳號： 
    cd worker
wrangler deploy
  4. 在 Extension 或 PWA 設定中填入你的 Worker URL
  5. 將同步碼分享給家人 — 同步碼會自動帶入你的 API 端點，家人無需額外設定
注意 — 同一家庭的所有成員必須使用相同的 API 端點。同步碼格式 moo-{id}-{key}@{host} 會自動處理這件事。

行動端 (PWA)

手機上無法安裝 Chrome Extension，但你可以透過 PWA 行動網頁瀏覽家庭開放書櫃。

功能ExtensionPWA
瀏覽家庭開放書櫃✓✓
建立 / 加入家庭✓✓
個人書櫃開放設定✓✓ (已同步的書)

PWA 無法直接爬取讀墨網頁書單。個人書櫃需先在桌面端 Extension 完成至少一次同步，之後即可在 PWA 調整開放設定。
