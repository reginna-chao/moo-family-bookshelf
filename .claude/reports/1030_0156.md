### 執行槓桿

- **E1** 大規模測試掃描：先派一個小 tester 只改共用 helper，落地後再派兩個 file-disjoint 的 tester 平行掃既有檔（unit／integration 各一），各自只跑自己的檔，最後 orchestrator 跑一次全套。
- **E2** security-auditor 的提示：列出要讀的檔與 `git show :<path>` 指令、明說「每次工具呼叫讀一個檔或一段 diff」，不要它讀 PLAN.md 全文；本 run 重派後的提示即可當範本。
- **E3** 執行計畫呈現給使用者時，新造的名詞（過渡、孤兒 token、空窗）各給一句定義：什麼時候發生、持續多久、使用者看得到什麼。
- **E4** 金魚找到設計級問題時，把「與今日相同」類的斷言各自標一個 `file:line`，寫不出來的就當 未驗證——本 run 計畫 L65 那句就寫不出對應的程式行。
