## 2. 卡點與摩擦

- **U1**（使用者，逐字）：「你可能要知道我沒有辦法像大公司一樣有無限的 Token」— 出現在決策關卡前。影響：五階段審查縮成兩種 persona、試跑只派一種、`model: inherit`、輸出上限 40 行。這個約束在 repo 任何規則檔裡都沒寫，每次 run 只能靠使用者重講。
- **G1**（金魚 G2 抓到）：GO 之後我連續執行步驟 4–6 沒有任何 Stop Block，PLAN.md 的進度表因此停在「⏳ 寫 goldfish agent」，直到金魚讀它時仍是舊的。規則只要求「每個 Stop Block 重抄」，自主執行的區段沒有 Stop Block，清單就過期；接手的 session 會重做三步。
- **G2**（金魚 G3 抓到）：同一 session 新增的 agent 不在 registry，只能走 general-purpose 備案，而備案路徑沒有 `omitClaudeMd`，試跑收到了 CLAUDE.md 與 `.claude/rules/`。結果是本 run 唯一驗證不到的就是這次導入的核心性質（隔離）。已寫成殘餘，留到下一個完整流程 run。
- **G3**：試跑成本 14.8 萬 token，其中載入 CLAUDE.md（約 350 行）與五個規則檔是備案路徑才有的開銷；正式路徑的成本沒有量到，code-cycle.md 步驟 7 的「worst case 四次派工」目前是估計，不是量測。
