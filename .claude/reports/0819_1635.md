- **G1（任務前提與 git 事實不符）**：任務敘述稱 tombstone「已由 fix/kicked-member-rejoin 分支引入」，實際該分支領先 origin/main **0 個 commit**，全部工作以未 commit 狀態存在於另一 session 的 worktree（bold-swartz-619627）。處置：讀取該 worktree diff → 匯出 patch → 在新分支 `feat/family-unkick` 上 `git apply` → 三包基線驗證全綠後才開工。風險：兩個 session 各持一份，落地需人工擇一。
- **G2（agent 基礎設施不穩）**：5 次死亡集中在長時間 FE 任務。有效模式：死亡後**全新重派**，若前手已在工作樹留下編輯，重派 prompt 改為「審核既有成果、補完、驗證、產摘要」而非重做；先 `git status`/diffstat 盤點再決定 prompt 形狀。
- **G3（恆真文案斷言直到聚焦重審才被抓到）**：所有文案斷言以 `getByText(builder(NAME))` 寫成，期望值與產品值同源；S3 改文案時**零測試變紅**才暴露。FE tester 與 FE reviewer 首輪都未攔截，第三隻眼（聚焦重審）才命中。
