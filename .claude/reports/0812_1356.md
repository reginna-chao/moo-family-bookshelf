## 2. 卡點與摩擦

- **U1**：首次 tester 派遣被使用者中斷（`[Request interrupted by user for tool use]`），經 AskUserQuestion 確認後才續行。本 run 以「autonomous 模式」跳過了 verify-before-test 停點，使用者恰在該處介入——本專案使用者實際上在看、且期望 gate 以 AskUserQuestion 呈現（與 memory `feedback_use_option_questions` 一致）。
- **G1**：3 次 agent 死亡重派（§3 重派規則有效，但約 29 萬 subagent tokens 沉沒）。
- **G2**：worktree 基底落後 origin/main 5 個 commit，Phase 0 只檢查了 ahead（`origin/main..HEAD`）沒檢查 behind。mid-run rebase 帶入 #99，恰好修掉 reviewer 已回報、我已開 follow-up chip 的既有 TTL<60 bug → chip 需撤回。
- **G3**：同一段註解改寫兩次：R1 依 reviewer 處方落地「~8 小時」宣稱，security scan 隨後指出該宣稱未涵蓋「未驗證流量走 per-IP 計數器 ~17 分鐘耗盡」的既有缺口，再派 coder 三改。安全數字類註解的事實查核發生在落地之後而非之前。
