- **G1 基礎設施中斷 ×3**：backend reviewer 死於 OAuth 401、frontend reviewer 隨 host process 退出、S1-S3 coder 死於 session limit。每次依規則棄部分產出、全新重派（原 prompt + cut-off 註記），共多耗 3 個完整派遣往返。重派前以 `git status` 驗證磁碟無殘留編輯，避免了重複套用。
