## 2. 卡點與摩擦

- **G1（分支基底過時）**：Phase 0 `git checkout -b … origin/main` 落在過時的 ref（`045f919`），實際 origin/main 已是 `5168b59`——恰為本任務的前置後端 PR #126。`git log --oneline origin/main..HEAD` 為空只能證明「不超前」，無法偵測「落後」。中途以 `git merge --ff-only origin/main` 補上並重跑整套驗證。
- **G2（任務清單漏鏡像元件）**：使用者提供的 call-site 清單漏了 `pwa/src/components/MemberList.tsx`（extension 同名元件的鏡像、打同一批被限流端點），靠首輪 reviewer 以 CRITICAL C1 補獲，多花一輪 coder + tester + focused re-review。清單型任務的「清單」不可假設完備。
- **G3（infra 失敗 ×4 + 1）**：兩次 stream stall、一次 529、一次 session-limit。皆依 SKILL §3 以全新 agent 原 prompt 重派；session-limit 的 tester 產出已寫盤，由 orchestrator 直接重跑雙套件回收，未重寫測試。第三次重派 reviewer 時在 prompt 加「lean style、避免 broad sweep」後成功。
- **G4（高併發 flake）**：extension + PWA 雙套件併發時 15+3 例逾時失敗，隔離重跑全綠；皆為既有 load-sensitive 測試（非本 diff 檔案）。已 spawn 獨立 deflake 背景任務，未混入本分支。

U#：無 mid-run 更正（autonomous run）；AskUserQuestion 四題中三題採建議選項，commit 一題使用者改選「只 commit（不 push / 不開 PR）」。
