## 2. 卡點與摩擦

- **U1**：「跳過手動驗證」。verify-before-test 關卡對這次幾乎純重構的改動價值低，唯一的新行為（Esc 關閉）可以完全用自動測試驗證。
- **G1**：base 在執行中前進了 3 個 commit（#218、#220、#221），其中 #220 改了 `pwa/src/components/BookSortDropdown.tsx` 的 import 路徑。這時改動還只在 staged 狀態，沒有 commit，而 stash 堆疊是各 worktree 共用的，不能用。最後的做法是：暫時 commit（`--no-verify`）→ `git rebase origin/main` → 手動解 import 衝突 → `git reset --soft origin/main`，改動回到 staged。`code-cycle.md` Phase 4 的 base re-check 只寫了「rebase/ff first」，沒有說明只有 staged 改動時該怎麼做。
- **G2**：用 Bash 呼叫 `gh` 時，`settings.local.json` 裡的 `GH_CONFIG_DIR` 沒有生效（提示要登入）；手動 export 並跳脫反斜線後輸出是空的。改用 PowerShell 設 `$env:GH_CONFIG_DIR` 並把 JSON 寫進檔案才讀到 issue。
