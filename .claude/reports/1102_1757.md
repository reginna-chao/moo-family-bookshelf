## 2. 卡點與摩擦

### U#（使用者修正，逐字）

- **U1**「我不知道是否可以從頁面 console 知道，目前看起來是無法，你可能要開 chrome 調查」— 決策關卡的 cookie 問題原本要使用者自己到 console 查；改由 orchestrator 用 Claude in Chrome 在使用者登入狀態下實測，一次定案（購買頁讀得到 `ReadmooNext.email`，可解碼成 email）。
- **U2**「除了 Options page，點開圖示 Page 以外，可以在家庭書櫃的設定頁面也能控制開關嗎？」— 分析只提了 options page；Dialog 端同一個開關是使用者補的需求，牽出「content script 沒有 permissions API → 背景鏡像到 storage」的設計。
- **U3**「options.html 可以更改字級大小嗎? 12 -> 14 (description) 14 -> 16 (label)」— verify gate 的 UI 回饋，一次 coder 處理。
- **U4**「options.html 的「已授權/未授權」可以改成 chip 嗎? 單色 check icon (不要 emoji)」— 同上，併進 Fix Round 1。
- **U5**「我確定我家人有這本書，但我沒看到標籤請問是哪裡操作錯誤嗎?」— 不是程式缺陷：擴充功能重新載入後，原本開著的讀墨分頁仍是舊 content script（孤兒），從它打開的 Dialog 不寫索引。verify gate 的說明沒有寫「重新載入擴充功能後，讀墨分頁也要重新整理」。
- **U6**「不能延長成 30 天嗎? (使用者怎麼知道因為太久沒有打開就不顯示，要在原地方顯示提示文字嗎？)」— C1 的修法：效期從建議的 7 天改 30 天，並加上過期提示 chip；提示不看書，避免洩漏過期的開放狀態。
- **U7**「你開 chrome 檢查」— 使用者偏好讓 orchestrator 直接用 Claude in Chrome 診斷，而不是貼指令給他跑。

### G#（關卡重試、失敗驗證、返工）

- **G1 金魚兩輪 24 項全採用**：Round 1 的 Blocker 是「要在不存在的測試檔加測試」；Round 2 的兩個 Blocker 是「`auth-refresh.ts` 釘在 364 行、剛好 364 行，加 import 必紅」與「`FamilySettings.test.tsx` 渲染真的 Provider，計畫寫的 mock 不存在」。三者都是 PLAN 引用了沒讀過的既有程式／測試。另外五處完全相等的 remove 斷言（`client.test.ts:1816` 等）grep 函式名找不到，金魚用 grep key 陣列才找齊。
- **G2 verify gate 的孤兒 content script**（U5）：花了一輪 Chrome 診斷才定位；chrome:// 與 chrome-extension:// 頁面 Claude in Chrome 打不開，擴充功能 storage 只能請使用者在設定頁按 F12 跑兩行指令。
- **G3 CRITICAL C1（索引無效期）**：Phase 1 風險表只寫了「自己離開家庭要清索引」，沒有「家人離開或取消開放後，本機快取會過期」。reviewer 用 2020 年的索引實測仍顯示才抓到。
- **G4 closed Shadow Root 擋不住 `Selection.modify`**：Fix Round 1 依 #362 慣例把 chip 放進 closed root；auditor 重掃用 PoC 證明 `window.find()` ＋ `Selection.modify()` 可直接讀出文字，`user-select: none` 才擋住。Dialog 自己的 Shadow Root 同樣適用 → issue #446。
- **G5 Fix Round 1 的 coder 跑不了 `pnpm typecheck`／`pnpm build`**：extension 的 `tsc --noEmit` 包含 `tests/`，coder 移除 `STORE_CHIP_ID` 後兩個 staged 測試檔編譯失敗（預期的紅），coder 只能拆步驟手動跑 build。
- **G6 建置環境與使用者環境不一致**：worktree 沒有 `.env`，第一版 dist 落回 dev Worker；orchestrator 複製 `.env*` 重建成正式版，但使用者的家庭在 dev Worker，自行 `pnpm build:dev` 重建。verify gate 的說明該先問清楚資料在哪個環境。
