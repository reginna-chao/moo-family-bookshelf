## 2. 卡點與摩擦

使用者沒有更正或中斷（U# 無）。

- **G1 — fix mode 的「EXACTLY ONE regression test」碰上「同一個修正落在兩個呼叫點」。** #265 的修正是同一行守衛，分別加在 `extension/src/sync/syncUpload.ts` 和 `extension/src/dialog/onboardingBooksUpload.ts`，兩個函式各自有測試檔，一個測試無法同時對兩者紅轉綠。`code-cycle.md` 規定 prompt 要逐字帶那句話，orchestrator 只好在逐字句後面再補一句「每個修正的函式各一個」，自行解釋規則，並在報告中揭露。規則沒寫這種情況，下一次可能被解讀成只測一邊。
- **G2 — 讀 `gh` 設定多了一次呼叫。** 第一次用 PowerShell 讀 `settings.local.json` 想取 `GH_CONFIG_DIR`，寫法把整份 JSON 指給了環境變數，結果沒用上；第二次才在 Bash 直接 `export` 已知路徑。memory 已經記著這個路徑。
