### C3. API 無認證機制（Dim 6）— ✅ 已修復

- **修復 commit：** `fc4ae49`（middleware）→ `7c9cf4f`（端對端整合）→ `479cced`（移除 fallback）
- **修復內容：**
  1. `worker/src/middleware/auth.ts` — Bearer token 認證 middleware
  2. 建立/加入家庭時自動產生 64-char hex token，存入 KV（雙向映射）

  4. 受保護 endpoint 強制要求認證（無 fallback）
  5. Token 格式驗證（`/^[a-f0-9]{64}$/`）
  6. Token TTL 90 天
  7. 離開家庭時清除 authToken

## WARNING 問題（建議修復）

### W1. 硬編碼 Cloudflare Workers 子網域（Dim 1）

- **位置：** `extension/src/constants.ts:11`, `pwa/src/constants.ts:10`
- **說明：** 預設 API endpoint fallback 包含 `rcworkadd.workers.dev`，暴露帳號識別碼。
- **修復：** 考慮使用自訂網域取代 Workers 子網域。

### W2. 依賴套件 HIGH 漏洞（Dim 2）

- **位置：** `worker/package.json` — `@cloudflare/vitest-pool-workers` 0.5.41
- **說明：** 4 個 HIGH 等級漏洞。皆在 devDependency 中，不影響 production bundle。
- **修復：** 升級 `@cloudflare/vitest-pool-workers` 至 `^0.13.4`。

### W3. vitest / vite 版本過舊（Dim 2）

- **位置：** 所有 `package.json`
- **說明：** vitest 2.1.9（最新 4.x）、vite 6.4.1（最新 8.x）。
- **修復：** 升級至最新主版本。

### W4. base64 解碼無 try-catch（Dim 3）

- **位置：** `extension/src/crypto/encrypt.ts`, `pwa/src/crypto/encrypt.ts`
- **說明：** `atob()` 可能因格式錯誤的 base64 輸入拋出例外。
- **修復：** 加入 try-catch wrapper。

### W5. PWA 加密金鑰明文存於 localStorage（Dim 3）— 已記錄為 Accepted Risk

- **位置：** `pwa/src/hooks/useAuth.ts`
- **說明：** PWA 無 chrome.storage，必須使用 localStorage。已在程式碼中加入 ACCEPTED RISK 註釋。
- **緩解措施：** 嚴格 CSP、無第三方 runtime 依賴。

### W6. manifest.json 缺少 CSP（Dim 4）

- **位置：** `extension/public/manifest.json`
- **說明：** 未定義 `content_security_policy`，僅依賴 MV3 預設值。
- **修復：** 加入明確的 CSP。

### W7. web_accessible_resources 過度寬泛（Dim 4）

- **位置：** `extension/public/manifest.json:19-23`
- **說明：** `src/*` 和 `chunks/*` 暴露過多資源。
- **修復：** 僅列出實際需要的檔案。

### W8. chrome.runtime.onMessage 缺少 sender 驗證（Dim 4）

- **位置：** `extension/src/background/index.ts`
- **說明：** 未驗證 message sender 身份和來源。
- **修復：** 驗證 `sender.tab` 和 `sender.url` 來自 readmoo.com。

### W9. production console.log 輸出敏感資料（Dim 5）— ✅ 已修復

- **修復 commit：** `532bd30`
- **修復內容：** 移除 PersonalShelf.tsx 中的所有 debug console.log，保留 warn/error。

### W10. CORS 未限制來源（Dim 6）

- **位置：** `worker/src/index.ts:15`
- **說明：** `cors()` 使用預設設定，允許所有來源。
- **修復：** 設定 origin 白名單。

### W11. Rate limiting 無差異化（Dim 6）

- **位置：** `worker/src/middleware/rateLimit.ts`
- **說明：** 所有 endpoint 統一 60 req/min。
- **修復：** 敏感 endpoint 降至 10-20 req/min。

### W12. 缺少安全性 HTTP headers（Dim 6）

- **位置：** `worker/src/index.ts`
- **說明：** 未設定 `X-Content-Type-Options`、`X-Frame-Options`、`Strict-Transport-Security`。
- **修復：** 新增安全性 headers middleware。

## 正面發現

- AES-256-GCM + `crypto.subtle` 實作正確，每次加密產生新 IV（12 bytes）
- 加密金鑰從未透過 API 傳送至伺服器（零知識架構）
- 無 `eval()`、`innerHTML`、`dangerouslySetInnerHTML` 等程式碼注入風險
- CI/CD 正確使用 `${{ secrets.* }}` 管理憑證
- `wrangler.toml` 使用 placeholder，不含真實 ID
- userId 輸入驗證（`isValidUserId()`）+ familyId 驗證（`isValidFamilyId()`）已正確實作
- Auth token 端對端整合，受保護 endpoint 強制認證
- QR Code URL 使用 fragment（#）保護加密金鑰不進入伺服器 log
- Sync code 解析器正確處理含 dash 的 familyId
- Token TTL 90 天 + 格式驗證 + 離開時清除
- Auth token 不在 console.log 中出現
- 所有外部連結使用 `rel="noopener noreferrer"`
- 無 PII、無內部 URL、無真實個資出現在原始碼中
- MIT License 正確設定
