# English

## Bug Fixes

- **Readmoo's new bookshelf domain is now supported.** Readmoo moved its bookshelf to `next.readmoo.com`, which left earlier versions unable to load a single book. Both the new and the legacy domain now work.
- Resetting your PIN or pattern on desktop now clears earlier failed attempts immediately, so you can sign in on your phone right away instead of waiting out the lockout.
- One-time codes no longer fail every time — the code was being consumed midway through sign-in.
- Saving your shelf during the final minute before a public link expires no longer fails with an error.
- Turning off public sharing no longer reports success when the server rejected it, so a link can never look revoked while still working.
- Turning sharing off on one device can no longer be undone by another device syncing moments later.
- Custom server addresses are now reliably remembered on Firefox.
- An unexpected borrow status falls back to a safe display instead of breaking the page.
- The mobile app now stays signed in through temporary network failures instead of logging you out.
- Status messages such as "saved" are no longer overwritten or cut short by an earlier one.
- Being removed from a family now explains why, instead of silently dropping you back to the onboarding screen.

## New Features

- **Undo an accidental removal.** Family owners can now lift a removal immediately from family settings instead of waiting six hours. It only lifts the restriction — the person still rejoins with the sync code.
- Lockout and rate-limit messages now show a live countdown of how long is left.

## Improvements

- Creating a family and looking up your family now require verification if you have a PIN, pattern, or one-time code set. Nobody can create a family on your account from your email address alone, or look up your sync code. **Please update the extension and PWA** — older versions do not send verification and will fail to create a family.
- A wrong PIN entered by someone else no longer locks you out. Failed attempts are now counted per connection source rather than against your account.
- Family owners can no longer silently move everyone to a different server. Members see both the current and the proposed address and must agree first, and a QR code carrying a custom server asks for confirmation before your phone contacts that server at all.
- Removing a member now actually sticks: they cannot rejoin for six hours, including automatic background reconnects. **Please update the extension and PWA** — older versions retry silently and may rejoin on their own once the six hours pass.
- Book cover images on borrow requests must now come from Readmoo, closing a hole where a modified client could use a cover URL to collect other family members' IP addresses and reading times.
- Revoked share links are now guaranteed dead, including shelves that have an expiry date.
- Malformed or hostile data from a custom server is ignored or replaced with safe defaults instead of reaching the screen. If you use the official server, nothing changes.
- Public shelf, verification, and family settings changes each gained a per-account hourly limit so one account cannot exhaust shared backend capacity.

# 繁體中文

## 問題修正

- **修正讀墨改版後擴充功能完全不能用的問題**：讀墨的書櫃換了網址（`next.readmoo.com`），舊版因此一本書都抓不到。現在新舊網址都支援，還沒換過去的帳號也能照常使用
- 修正忘記 PIN 後解不開的問題：在電腦上重設 PIN 或圖形驗證後，先前累積的失敗紀錄立刻失效，可以馬上在手機登入，不用等鎖定時間過完
- 修正用「隨機驗證碼」登入時一定會失敗的問題——驗證碼先前會在流程中途就被用掉
- 修正公開書櫃在「快到期的最後一分鐘」儲存書單或改設定會失敗的問題
- 修正「關閉公開分享」失敗卻顯示已關閉的問題：現在只有伺服器確認成功才會顯示已關閉，不會讓你以為連結撤銷了、其實還打得開
- 修正在一台裝置關閉分享後、另一台裝置可能把它重新打開的問題
- 修正 Firefox 上伺服器位址有時沒被記住、下次開啟又連回預設伺服器的問題
- 修正借閱狀態顯示異常的問題：收到預期外的狀態時改用安全的預設顯示，不會讓整個畫面出錯
- 修正手機版在網路不穩時會直接被登出的問題：暫時性的連線失敗現在會保留登入狀態並重試
- 修正儲存或同步後的「已儲存」等提示，偶爾被上一次的提示蓋掉或提早消失的問題
- 被家庭管理者移出時，擴充功能會在畫面上說明原因，不再無聲跳回一開始的引導畫面

## 功能新增

- 家庭設定新增「解除移除限制」：管理者不小心移除成員後，按一下就能讓對方馬上重新加入，不必等 6 小時。這個動作只解除限制，不會自動把人加回家庭，對方仍要自己用同步碼加入
- 被鎖定或操作太頻繁時，畫面會直接顯示還要等幾秒並即時倒數，不必自己猜要等多久

## 改善調整

- 「建立家庭」與「查詢所屬家庭」現在也需要通過驗證：有設定 PIN、圖形或驗證碼的人，別人無法再單憑你的 Email 幫你的帳號建立家庭並取得存取權，也查不到你的同步碼。沒設定驗證的人行為不變
  - **請更新擴充功能／PWA**：舊版不會送出驗證資訊，若你有設定 PIN／圖形／驗證碼，舊版會誤判成「尚未加入家庭」並在建立家庭時失敗
- 別人猜錯你的 PIN 不會再鎖住你：驗證失敗改成只鎖住猜錯的那個連線來源，不再記在你的帳號上
- 家庭管理者更換伺服器不再無聲生效：其他成員會先看到目前與即將切換的位址，同意後才會切換；手機掃到帶有自訂伺服器的 QR Code 時，也會先顯示位址等你確認，在你確認之前不會向那台伺服器送出任何連線
- 管理者移除成員現在會真的生效：被移除的人 6 小時內無法重新加入同一個家庭，包含背景自動重連。自願離開家庭不受影響
  - **請更新擴充功能／PWA**：舊版不認得這個回應，會在背景一直重試又不說原因，6 小時後甚至可能自動重新加入
- 修補借閱請求可被植入追蹤圖片的漏洞：書封網址必須是 Readmoo 的網址，避免有人藉自訂書封取得其他家人的 IP 與開啟時間
- 關閉分享或重設連結後，舊連結一定打不開了，設有到期日的書櫃同樣適用
- 加強對「伺服器回傳怪資料」的防護：自訂伺服器若回傳格式不對或帶有惡意內容的資料，現在會直接忽略或改用安全的預設值顯示。使用官方伺服器的人不受影響
- 公開書櫃、驗證設定與家庭設定的變更，各自加上每小時最多 30 次的上限，避免單一帳號短時間大量操作而影響到所有使用者
