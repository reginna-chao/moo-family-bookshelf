# English

## Bug Fixes

- **Readmoo's new bookshelf address is now supported.** Readmoo moved its bookshelf to `next.readmoo.com`, and earlier versions could not load a single book. Both the new and the old address work now.
- Reset your PIN or pattern on the computer and you can sign in on your phone straight away, without waiting out the lockout.
- One-time codes work again — they used to fail every time.
- Saving your shelf in the last minute before a public link expires no longer fails.
- Turning off public sharing now shows a real error when it fails, so a link can never look revoked while it still opens.
- Turning sharing off on one device can no longer be undone by another device.
- Custom server addresses are remembered properly on Firefox.
- An unexpected borrow status no longer breaks the whole page; that record just reads "status unknown".
- The phone app stays signed in through a flaky connection instead of logging you out.
- Messages like "saved" are no longer cut short by an earlier one.
- Being removed from a family, the family being dissolved, or the family being full is now explained on screen instead of dropping you back to the welcome page with no reason.

## New Features

- **Undo an accidental removal.** A family owner can lift a removal with one click instead of waiting six hours. It only lifts the restriction — the person still rejoins with the sync code.
- Lockout and "too many attempts" messages now count down the seconds left.

## Security & Privacy

- If you have a PIN, pattern, or one-time code set, nobody can create a family on your account from your email address alone, and nobody can look up your sync code. Nothing changes if you have no verification set.
  - **Please update the extension and PWA.** The extension updates itself, usually within a few hours; restarting the browser speeds it up. For the PWA, reload the page. Without the update, creating a family fails if you have verification set; everyday use in a family you already joined is unaffected.
- Someone else guessing your PIN wrong no longer locks you out; only the side that guessed wrong is locked.
- Each account allows 10 failed verification attempts per hour. Only wrong guesses count, so even if someone uses up your account's attempts, the correct PIN, pattern, or code still gets you in.
- A family owner changing the server now has to be agreed to: everyone sees the current and the proposed address first.
- A QR code carrying a custom server shows you the address and waits for your confirmation; your phone does not contact that server until you confirm.
- Removing a member sticks: they cannot rejoin the same family for six hours — by sync code, by QR code, or by an automatic background reconnect. Leaving voluntarily is unaffected.
  - **Please update the extension and PWA** (same steps as above). Older versions retry silently and may rejoin on their own after six hours.
- A borrow request is rejected unless the book cover comes from a Readmoo address, so viewing a cover never hands your connection details to a third-party site. Covers already stored that fail the check show as blank.
- Malformed or hostile data from a custom server is ignored or replaced with a safe default instead of reaching the screen. Nothing changes if you use the official server.
- Revoked share links are reliably dead, expiry-dated shelves included, and an expired link always reads "not found or expired".
- Public shelf, verification, and family settings changes each allow 30 changes per hour. Normal use never reaches it.

# 繁體中文

## 問題修正

- **修正讀墨改版後擴充功能完全不能用的問題**：讀墨的書櫃換了網址（`next.readmoo.com`），舊版因此一本書都抓不到。現在新舊網址都支援，還沒換過去的帳號也能照常使用。
- 在電腦上重設 PIN 或圖形驗證後，可以馬上在手機登入，不用等鎖定時間過完。
- 修正用驗證碼登入時一定會失敗的問題。
- 修正公開書櫃在快到期的最後一分鐘儲存書單或改設定會失敗的問題。
- 「關閉公開分享」失敗時會如實顯示錯誤，不會再讓你以為連結撤銷了、其實還打得開。
- 在一台裝置關閉分享後，另一台裝置不會再把它重新打開。
- 修正 Firefox 上伺服器位址有時沒被記住、下次開啟又連回預設伺服器的問題。
- 借閱狀態顯示異常時不會再讓整個畫面出錯，那筆紀錄會顯示成「狀態未知」。
- 手機版遇到網路不穩不會再直接把你登出，會保留登入狀態並重試。
- 修正「已儲存」這類提示偶爾被上一次的提示蓋掉或提早消失的問題。
- 被移出家庭、家庭已解散、或人數已滿而無法加入時，擴充功能會在畫面上說明原因，不再無聲跳回一開始的引導畫面。

## 功能新增

- 家庭設定新增「解除移除限制」：管理者不小心移除成員後，按一下就能讓對方馬上重新加入，不必等 6 小時。這個動作只解除限制，對方仍要自己用同步碼加入。
- 被鎖定或操作太頻繁時，畫面會直接顯示還要等幾秒並即時倒數。

## 安全與隱私

- 有設定 PIN、圖形或驗證碼的人，別人已經無法單憑你的 Email 幫你的帳號建立家庭，也查不到你的同步碼。沒設定驗證的人行為不變。
  - **請更新擴充功能／PWA**：擴充功能會自動更新，通常幾小時內完成，想快一點可以重新啟動瀏覽器；手機版重新整理頁面即可。沒更新的話，有設定驗證的人會在建立家庭時失敗，已加入家庭的日常操作則不受影響。
- 別人猜錯你的 PIN 不會再鎖住你，只會鎖住猜錯的那一方。
- 同一個帳號每小時最多 10 次驗證失敗。只有猜錯才計入，所以就算有人把你帳號的次數用完，你自己輸入正確的 PIN、圖形或驗證碼一樣照常通過。
- 家庭管理者更換伺服器時，其他成員會先看到目前與即將切換的完整位址，同意後才會切換。
- 手機掃到帶有自訂伺服器的 QR Code 時會先顯示位址等你確認，在你確認之前不會向那台伺服器送出任何連線。
- 管理者移除成員現在會真的生效：被移除的人 6 小時內無法重新加入同一個家庭，手動輸入同步碼、掃 QR Code 與背景自動重連都一樣。自願離開家庭不受影響。
  - **請更新擴充功能／PWA**（方式同上）：舊版不認得這個回應，會在背景一直重試又不說原因，6 小時後甚至可能自動重新加入。
- 建立借閱請求時，書封網址必須是 Readmoo 的網址，其他會被拒絕，家人看書封時不會把自己的連線資訊送給第三方網站。先前已存在的異常書封會顯示為空白書封。
- 加強對「伺服器回傳怪資料」的防護：自訂伺服器若傳回格式不對或帶有惡意內容的內容，現在會直接忽略或改用安全的預設值顯示。使用官方伺服器的人不受影響。
- 關閉分享或重設連結後，舊連結一定打不開了，設有到期日的書櫃同樣適用，過期連結一律顯示「找不到或已過期」。
- 公開書櫃、驗證設定與家庭設定的變更，各自加上每小時最多 30 次的上限。一般使用碰不到。
