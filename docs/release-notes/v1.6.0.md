# English

## New Features

- **Favorites in the family shelf** — mark books you love and toggle "favorites only". Like hiding, it's a private, per-viewer preference: it only affects your own view, and family members can't see what you've favorited.
- **Descending sort (Z→A)** — sort by title or author in reverse order.
- **Refreshed filter & sort menus** — dropdowns now pair icons with text, tabs gained icons, and the mobile layout and titles were polished.
- **Responsive dialog on mobile** — the dialog now adapts to phone screens (including Firefox for Android™).
- **Keyboard navigation** — the book-sort dropdown is now operable by keyboard (arrows / Enter / Esc).

## Improvements

- **Stronger re-join / recovery verification** — members who set a PIN or pattern are now prompted for it when re-joining or recovering a family on a new device, preventing account impersonation; backend input validation was also hardened.
- The public-shelf settings no longer submit a half-typed title if you close the dialog immediately after typing.
- Updated a backend dependency (hono) to clear a security advisory.

## Bug Fixes

- Fixed an abnormal desktop dialog height on the main view.
- Fixed familyId occasionally not persisting on Firefox.
- Fixed the Firefox data-collection permission declaration (add-on store compliance).

# 繁體中文

## 功能新增

- 家庭書櫃新增「我的最愛」：可標記喜歡的書並切換「只看最愛」，僅影響自己的檢視，家人不會知道你標記了哪些書
- 書櫃排序新增降冪（Z→A）選項，書名與作者皆可反向排序
- 篩選 / 排序選單改為「圖示 + 文字」樣式，分頁加上圖示，並優化手機版版面與標題呈現
- 對話框支援手機版響應式版面（含 Firefox 行動版）
- 書籍排序下拉選單支援鍵盤操作（方向鍵 / Enter / Esc）

## 改善調整

- 強化家庭「重新加入 / 復原」驗證：有設定 PIN / 圖形驗證的使用者，在新裝置重新加入或復原時會被要求輸入驗證，避免他人冒用帳號；同時強化後端輸入驗證
- 修正公開書櫃設定：在標題輸入後隨即關閉視窗時，不再送出未完成的變更
- 更新後端相依套件（hono），修補安全告警

## 問題修正

- 修正桌面版對話框在主畫面的高度異常
- 修正 Firefox 上 familyId 有時無法保存的問題
- 修正 Firefox 擴充功能的資料蒐集權限宣告（附加元件商店上架合規）
