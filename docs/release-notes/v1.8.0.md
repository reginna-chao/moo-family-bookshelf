# English

## Bug Fixes

- Extension: on Firefox (including Android), changes to the auto-sync interval, archived-book syncing, the Family Shelf button size and the shelf sort order are now remembered instead of snapping back.
- Sync now removes books that are no longer on your Readmoo bookshelf (refunded books, for example) from the personal shelf, and tells you how many were removed and how many of them were shared. Books on loan and archived books are never removed.
- Extension: books whose title is over 200 characters are no longer added to the personal shelf; books with an overly long author or category are still added, just without that field. Everything else syncs as usual.
  - **Please update the extension.** An extension that has not updated yet fails the whole sync when it meets such a book. The extension updates itself, usually within a few hours; restarting the browser speeds it up.
- If a book already on your personal shelf ends up with a title over 200 characters, the shelves show a "title too long" placeholder instead; it comes back at the next sync once the title is shorter.
- Books on the family shelf with no author, or an author name over 100 characters, can now be requested for borrowing. Families on a self-hosted server get this fix once the administrator updates the server.
- Extension: if the share settings you set on the personal shelf did not reach the server when you created or joined a family, the next sync saves them again instead of dropping them.
- The extension and the PWA no longer wrongly report that they cannot get the self-hosted server's version every time they open. Families on a self-hosted server get this fix once the administrator updates the server.
- PWA: opening a malformed invite link no longer signs you out, and "Remember sync code" keeps the choice you made.
- Families on a self-hosted server: when the server sends back malformed data, the extension and the PWA now ignore it or fall back to safe defaults, and PWA sign-in no longer gets stuck on a verification screen with no input box and no cancel button.
- PWA: switching the family shelf to another member now clears the search box, so a leftover search no longer makes it look as if that member has no books.
- PWA: books you have asked to borrow now show "Requested" in both the list and the grid view of the family shelf, the same as in the extension.
- Extension: with a screen reader, each book's share button on the personal shelf reads out the title and whether the book is shared, and the cover no longer repeats the title.
- In the family and personal shelf sort menus, Tab now closes the menu; to change the sort, pick an option with the arrow keys and press Enter.
- Extension: a drawn unlock pattern is now sent only when you press Confirm, as in the PWA. Confirm stays disabled until the PIN has 6 digits or the pattern has 4 dots, and a counter below shows how far you are.
- PWA: choosing a random verification code the first time you set up sign-in verification is now saved reliably, instead of sometimes falling back to no verification.
- PWA: as long as you open it at least once every 30 days, your sign-in now renews itself, with no need for the extension and no re-entering your PIN or pattern.

## New Features

- Extension: a new "new books shared by default" setting, off by default. When it is on, books that sync adds to your personal shelf for the first time (newly bought books, or books moved back from the archive) are shared with your family automatically and also appear on your public shelf. Nothing is auto-shared on the first sync or when more than 100 books arrive at once, and a book you set to not shared stays that way if it is removed and later synced back. Families on a self-hosted server can use it once the administrator updates the server.
- Forgot your sign-in verification? The verification screen and the setup hint now link to a recovery request form (official server only). Once the administrator confirms, a temporary PIN is emailed to the address registered with your Readmoo account.
- Extension: on a Readmoo book page, if a family member shares that book, a line under the title shows who. Names come from the last time you opened the family shelf, and after 30 days without opening it a reminder appears instead. The feature is off by default: turn it on from the extension's toolbar icon or under personal settings in Settings, and allow the extension to read readmoo.com book pages the first time.
  - From this version the Firefox build (including Android) needs Firefox 128 or later. On Firefox 121–127 this update never arrives and no notice is shown, so please update Firefox first.
- Family settings now has a link button next to "Invite members to the family" that copies only the invite link, without the invite message.

## Performance

- Extension: while the family shelf window is open, the extension no longer keeps re-running in the background, which slowed Readmoo pages down and drained battery.
- Covers that are still loading now show a plain light-grey placeholder instead of a spinner, which also saves power while the shelf sits idle.

## Security & Privacy

- Deleting your account now also deletes your PWA sign-in verification (PIN, pattern or verification code), so creating or joining a family again with the same Readmoo account no longer asks for the old one. Families on a self-hosted server get this once the administrator updates the server.
- Server logs no longer record sync codes, public-shelf share links or family members' account IDs.
  - **Self-hosters**: adjust the settings as described in the invocation-log section of `worker/DEPLOY.md`, then redeploy.
- Nobody can use the server to find out whether you have used the PWA. Families on a self-hosted server get this once the administrator updates the server.
- Extension: your Readmoo email is now used only to confirm the account and is no longer stored in the browser. Emails stored by older versions are deleted once the extension updates.
- Extension: other scripts running on Readmoo pages can no longer see the PIN, pattern or sync code you enter, or the sync code, verification code and QR code on screen, and can no longer press buttons in the family shelf window for you. Everyday use feels the same.
- After you set or change a PIN or pattern, your other signed-in devices must pass the new verification to keep going; the device you made the change on is unaffected, and switching to a verification code or to no verification leaves signed-in devices alone. Families on a self-hosted server get this once the administrator updates the server.
  - **Please update the extension and PWA.** An extension that has not updated asks you to verify again the next time it talks to the server after the change; a PWA that has not updated signs you out after you set a PIN or pattern — reload the page to update it and sign in once more. The extension updates itself, usually within a few hours; restarting the browser speeds it up.
- Changing your sign-in verification or deleting your account now requires your current PIN or pattern first (accounts using a verification code or no verification are exempt). If you have forgotten it, you cannot reset it yourself, even on a computer where the extension is still signed in. Families on a self-hosted server get this once the administrator updates the server.
  - **Please update the extension and PWA.** Once the server is updated, an extension or PWA that has not updated fails to change verification or delete the account on accounts with a PIN or pattern. The extension updates itself, usually within a few hours; restarting the browser speeds it up. Reload the PWA page to update it.
- PIN and pattern hashes now use a secret key only the server knows, so even a leaked server backup cannot be used to guess your PIN or pattern. It is already on for the official server; a PIN or pattern you set earlier is protected after your next sign-in.
  - **Self-hosters**: see the PIN-hash pepper section of `worker/DEPLOY.md`.
- The server no longer stores each device's sign-in credential itself. After the update every device signs in once more: automatically for accounts without a PIN or pattern, and by entering it again for accounts with one.
  - **Self-hosters**: read the Update section of `worker/DEPLOY.md` before updating the server.
- An account keeps at most 5 sign-ins at a time, and signing in again on the same device also counts as one; the 6th sign-in signs out the oldest. Families on a self-hosted server get this once the administrator updates the server.
- For accounts with a PIN or pattern, each device must enter it again no later than 180 days after signing in; accounts using a verification code are not affected. Families on a self-hosted server get this once the administrator updates the server.

## UI

- The sign-in verification setup screen now explains that the extension on your computer must also pass this verification when it signs in again. In the extension's Settings, "Mobile sign-in" is renamed "Mobile sign-in & verification".
- PWA: the sort menu, the "⋯" book menu and the public-shelf share dialog are easier to use from the keyboard: arrow keys move through the menus and Esc closes the dialog. Screen readers announce that the sort, member and category buttons open a menu, and read the share dialog as a dialog.
- Extension: the auto-sync interval description in Settings now says correctly that sync runs when you open the personal shelf and the chosen time has passed since the last sync, not on a background timer.
- Extension: after "Save changes" on the personal shelf succeeds, the button shows "Saved" before it hides.
- PWA: the manual lending reminder now has a close button in its top-right corner.

# 繁體中文

## 問題修正

- 擴充功能：在 Firefox（包括 Android 版）上，「自動同步頻率」、「同步封存書籍」、「家庭書櫃按鈕大小」和書櫃的排序方式改了會記住，不會再自己跳回原來的設定。
- 同步書單時，讀墨書櫃裡已經沒有的書（例如退款的書）會從個人書櫃移除，畫面會顯示移除了幾本、其中幾本原本設為分享。借出中和封存的書不會被移除。
- 擴充功能：同步時，書名超過 200 個字的書不會加進個人書櫃；作者或分類太長的書還是會加進來，只是不顯示太長的那一欄。其他書照常同步。
  - **請更新擴充功能／PWA**：還沒更新的擴充功能遇到這種書，整份書單都會同步失敗。擴充功能會自動更新，通常幾小時內完成，想快一點可以重新啟動瀏覽器。
- 已經在個人書櫃裡的書，如果書名變得超過 200 個字，書櫃上會顯示「（書名太長，無法顯示）」；書名改短後，下次同步就會恢復。
- 家庭書櫃裡沒有作者資料、或作者名字超過 100 個字的書，現在可以申請借閱了。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 擴充功能：建立或加入家庭時，之前在個人書櫃設好的分享設定如果沒能存到伺服器，接著同步書單時會再存一次，不會就這樣被清掉。
- 擴充功能和 PWA 打開時，不會再每次都誤報「無法取得自架伺服器版本資訊」。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- PWA：打開內容有誤的邀請連結，不會再把你登出；「記住同步碼」也會維持你原本的選擇。
- 使用自架伺服器的家庭：伺服器回傳格式不對的資料時，擴充功能和 PWA 會忽略它或改用安全的預設值，PWA 登入也不會再卡在沒有輸入框、也沒有取消鍵的驗證畫面。
- PWA：在家庭書櫃改看另一位成員的書時，搜尋框會清空，不會再因為留著剛才搜尋的字，看起來像這位成員沒有書。
- PWA：家庭書櫃用列表或網格檢視時，你已經申請借閱的書都會顯示「申請中」，和擴充功能一樣。
- 擴充功能：用螢幕閱讀器操作個人書櫃時，每本書的分享按鈕會唸出書名和目前是否開放分享，書封不再重複唸一次書名。
- 家庭書櫃和個人書櫃的排序選單打開時，按 Tab 會關閉選單；要換排序，請用方向鍵選好再按 Enter。
- 擴充功能：解鎖圖形畫完要按「確認」才會送出，和 PWA 一樣。PIN 碼不到 6 位、圖形不到 4 個點時不能按「確認」，下方會顯示已輸入幾位或已連幾個點。
- PWA：第一次設定登入驗證時選「隨機驗證碼」，現在會確實存下來，不會再被改回「不設定驗證」。
- PWA：只要至少每 30 天打開一次，登入就會自動延長，不必用擴充功能，也不會因為登入過期又要重新輸入 PIN 碼或圖形。

## 功能新增

- 擴充功能：設定裡多了預設關閉的「新書預設開放」，打開後，同步時個人書櫃裡還沒有的書（例如新買的書、從封存移回書櫃的書）會自動開放給家人，也會出現在你的公開書櫃。第一次同步或一次新增超過 100 本書時不會自動開放，你設為不開放的書從個人書櫃移除後再同步回來，也會維持不開放。使用自架伺服器的家庭，要等管理者更新伺服器才能使用。
- 忘記登入驗證方式時，登入驗證畫面和驗證方式的設定提示旁多了「填寫救援申請」的連結（只有使用官方伺服器時會出現）；管理者確認後會把臨時 PIN 寄到你的讀墨註冊 Email。
- 擴充功能：在讀墨的書籍頁面，如果家人開放了這本書，書名下方會顯示是誰開放的；名字以你上次打開家庭書櫃時為準，超過 30 天沒打開就改成顯示提醒。這個功能預設關閉，要打開可以點瀏覽器工具列上的墨家書櫃圖示，或到「設定」的個人設定；第一次打開要允許擴充功能讀取 readmoo.com 的書籍頁面。
  - Firefox 版（包括 Android 版）從這一版起需要 Firefox 128 以上。還在用 Firefox 121 到 127 的人不會收到這次更新，也不會有任何提示，請先把 Firefox 更新到最新版。
- 家庭設定的「邀請成員加入家庭」旁多了一個連結按鈕，按一下只會複製邀請連結，不含邀請訊息。

## 效能改善

- 擴充功能：開著家庭書櫃視窗時，擴充功能不會再在背景不停重複執行，拖慢讀墨網頁、增加電腦耗電。
- 還沒載入完成的書封改成只顯示淺灰底，不再轉圈圈。書櫃開著不動時也比較省電。

## 安全與隱私

- 移除帳戶時，PWA 登入驗證設定（PIN 碼、圖形或驗證碼）也會刪除，之後用同一個讀墨帳號重新建立或加入家庭，不會再被要求通過舊的驗證。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 伺服器的運作紀錄不會再記下同步碼、公開書櫃的分享連結和家人帳號的識別碼。
  - 自架伺服器的人，請照 `worker/DEPLOY.md` 的「不記錄請求網址（invocation log）」一節調整設定，再重新部署。
- 其他人不能再透過伺服器查出你有沒有用過手機版（PWA）。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 擴充功能：讀墨帳號的 Email 只用來確認帳號，不會再存在瀏覽器裡。舊版存下的 Email，擴充功能更新後會自動刪除。
- 擴充功能：你輸入的 PIN 碼、圖形和同步碼，還有畫面上顯示的同步碼、驗證碼和 QR Code，讀墨頁面上執行的其他程式都看不到，也沒辦法替你按家庭書櫃視窗裡的按鈕。日常使用感覺不到差別。
- 設定或更改 PIN 碼、圖形驗證之後，你其他已經登入的裝置要通過新的驗證才能繼續使用，做這次設定的裝置不受影響；改成驗證碼或不驗證，不影響已經登入的裝置。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
  - **請更新擴充功能／PWA**：還沒更新的擴充功能改完之後，下一次和伺服器連線時會要你再驗證一次；還沒更新的 PWA 設好 PIN 碼或圖形驗證後會被登出，重新整理頁面就會更新，再登入一次就好。擴充功能會自動更新，通常幾小時內完成，想快一點可以重新啟動瀏覽器。
- 更改登入驗證或移除帳戶前，要先輸入目前的 PIN 碼或圖形（設成驗證碼或不驗證的帳號不用）；忘記的話，就算電腦上的擴充功能還登入著，也沒辦法自己重設。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
  - **請更新擴充功能／PWA**：伺服器更新之後，還沒更新的擴充功能和 PWA，在設了 PIN 碼或圖形的帳號上更改登入驗證或移除帳戶都會失敗。擴充功能會自動更新，通常幾小時內完成，想快一點可以重新啟動瀏覽器；PWA 重新整理頁面就會更新。
- PIN 碼和圖形驗證多了一把只有伺服器知道的祕密金鑰：就算伺服器的備份資料外流，也沒辦法從中猜出你的 PIN 碼或圖形。官方伺服器已經啟用；已經設好的 PIN 碼或圖形，下次登入後就會受到保護。
  - 自架伺服器的人，請照 `worker/DEPLOY.md` 的「設定 PIN 雜湊的 pepper（建議）」一節設定。
- 伺服器不再保存各裝置的登入憑證本身。更新後每台裝置都會重新登入一次：帳號沒設 PIN 碼或圖形驗證的會自動完成，設了的要再輸入一次。
  - 自架伺服器的人，更新伺服器前請先看 `worker/DEPLOY.md` 的「更新」一節。
- 同一個帳號最多同時保留 5 個登入，同一台裝置重新登入也算一個；第 6 次登入時，最早的那個登入會被登出。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 設了 PIN 碼或圖形驗證的帳號，每台裝置登入後最長 180 天就要再輸入一次 PIN 碼或圖形；設成驗證碼的帳號不受這個限制。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。

## 介面調整

- 設定登入驗證（PIN 碼、圖形驗證或驗證碼）的畫面，現在會說明電腦上的擴充功能重新登入時也要通過這個驗證。擴充功能「設定」裡的「手機版登入」改名為「手機登入與驗證」。
- PWA：排序選單、書籍的「⋯」選單和公開書櫃分享視窗現在更方便用鍵盤操作，選單可以用方向鍵挑選項目，分享視窗可以按 Esc 關閉。螢幕閱讀器會讀出排序、成員和分類按鈕可以打開選單，分享視窗也會被讀成對話框。
- 擴充功能：設定裡「自動同步頻率」的說明已更正，寫明是在開啟個人書櫃、且距離上次同步超過選定的時間時才會自動同步，不會在背景定時同步。
- 擴充功能：個人書櫃按下「儲存變更」並存好後，按鈕會先顯示「已儲存」再收起來。
- PWA：手動借出提醒的視窗右上角多了關閉按鈕。
