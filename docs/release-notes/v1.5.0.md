# English

## New Features

- **Hidden books in the family shelf** — hide books you'd rather not see in the family bookshelf. Hiding is a private, per-viewer preference: it only affects your own view (family members are unaffected), it's fully reversible, and you can toggle to review what you've hidden.
- **Firefox support (desktop & Firefox for Android™)** — the extension is now available for Firefox. Install it from the Firefox Add-ons store, or download the signed `.xpi` for direct install with automatic updates.

# 繁體中文

## 功能新增

- 家庭書櫃新增「隱藏書籍」：可把不想看到的書隱藏，僅影響自己的檢視（家人不受影響），可隨時取消隱藏，並能切換檢視已隱藏的書
- 推出 Firefox 版擴充功能，支援 Firefox 桌面版與 Firefox for Android™：可從 Firefox 附加元件商店安裝，或下載簽章版 `.xpi` 自行安裝（含自動更新）
