# English

## Bug Fixes

- Extension: when the shelf asks you to re-enter your PIN or pattern, hidden books stay hidden afterwards, with no page reload needed.
- Extension: if a favorite or hidden-book change did not reach the server, it is saved again once you re-enter your PIN or pattern, and the warning goes away when it succeeds.
- If a favorite or hidden-book change did not reach the server, it is also saved again when you close the shelf window (the PWA has no such window and saves when you sign out). If that attempt fails too, the change is lost.
- When favorites or hidden books cannot sync, the warning no longer tells you to reload the page, since reloading would lose the unsaved change.
- Extension: if you confirm a server switch while a sync is running, that sync stops and asks you to sync again, instead of writing the book list read from the old server to the new one.
- If something goes wrong while deleting your account, press delete again to finish the job; even if you don't, the account is finished off automatically, and by then it is too late to change your mind. Your PIN or pattern verification is removed only after everything else is gone. Families on a self-hosted server get this once the administrator updates the server.
- If the account was already deleted but the screen never got the result, pressing delete again now completes instead of showing an error. Families on a self-hosted server get this once the administrator updates the server.
- After an account is deleted, a sync or settings change still in progress can no longer bring the book list or public links back; anything not cleared right away is usually gone within about 30 minutes.
  - **Self-hosters**: update the server and add the scheduled job described under "帳號刪除的定時清理" in `worker/DEPLOY.md`.
- For about 2 minutes after an account is deleted, the same account cannot create or join a family; the screen asks you to try again shortly. Families on a self-hosted server get this once the administrator updates the server.
- Extension: if you are removed, or the family is disbanded, during the first sync after joining, you go back to the start screen with an explanation instead of landing on a family shelf that will not open and an English error message.
- Extension: after leaving, being removed from or rejoining a family, the extension no longer occasionally snaps back to an earlier state, such as showing a family you are no longer in with a second removal notice, or asking you to join again right after you rejoined.
- Extension: when you need to re-enter your PIN to sign in, you can start typing straight away without clicking the input box first.
- Extension: with the shelf open in two tabs and one of them already out of the family, pressing "Confirm switch" for a server switch in the other tab no longer switches; it asks you to close and reopen the shelf.

## New Features

- Four settings now follow your account instead of the browser: syncing archived books, the auto-sync interval, "show books your family shares on the store page" and the Family Shelf button size. Change one in a browser and your other browsers pick it up the next time you open the shelf; archived-book syncing is also shared with the PWA. Families on a self-hosted server get this once the administrator updates the server.
  - If the store-page switch was turned on in another browser, this browser still needs permission once: open the extension's options page and press "Grant".

## Security & Privacy

- Extension, for families on a self-hosted server: while you leave or are removed from a family, sync your book list, save the personal shelf, or create or join a family, your book list, favorites and hidden books, sign-in credentials and the PIN or pattern you enter are never sent to the official server.
- Extension: requests to leave a family, delete your account, transfer ownership or change your sign-in verification go only to the server you were using on that screen. This only affects families on a self-hosted server.
- Extension and PWA: if you have used a self-hosted server, sign-in credentials are sent only to the server that issued them.
- Extension: after you confirm a server switch, the extension rejoins your family automatically; if you use a PIN or pattern, you may need to verify once more.
- Extension: if you use a random verification code, change it to a PIN or pattern before switching servers, or you may not be able to rejoin the family.
- Extension: on a device that is not in any family, requests to create or join a family go only to the official server, the server in the sync code, or a server the administrator set on that device, never to the previous family's server. This only affects families on a self-hosted server.
  - **Self-hosters**: the way to set a server on a device that has not joined a family has changed; see section 9 of `worker/DEPLOY.md`.
- After 10 wrong PIN, pattern or verification-code attempts on one account within an hour, even the correct one is refused until the next hour. Devices that are still signed in keep working, and the extension can still show a QR Code to sign in a phone. Families on a self-hosted server get this once the administrator updates the server.
- Signing in with a QR Code no longer signs out devices that signed in with your PIN or pattern; if all 5 of the account's sign-ins used a PIN or pattern, scanning a QR Code asks for the PIN or pattern instead. Families on a self-hosted server get this once the administrator updates the server.
- When confirming your current PIN or pattern, each sign-in gets 5 wrong attempts per hour, so someone else's wrong guesses cannot stop you from changing your PIN; devices signed in by QR Code share those 5. Families on a self-hosted server get this once the administrator updates the server.
- If sign-in keeps saying "too many attempts", the administrator can, after confirming it is you, send a one-time rescue link and a temporary PIN. Open the link in your usual browser to sign in, then change the PIN right away. Families on a self-hosted server get this once the administrator updates the server.
- The hourly limits on wrong PIN, pattern or verification-code attempts (10 at sign-in, 5 per sign-in when confirming your current PIN or pattern) are now counted more reliably. Everyday use feels the same.
  - **Self-hosters**: update the server and add the new configuration described in step 6 of `worker/DEPLOY.md`; without it the server still works, just without this improvement.
- Leaving a family or transferring ownership now requires your current PIN or pattern first, the same as deleting your account (accounts using a verification code or no verification are exempt). Families on a self-hosted server get this once the administrator updates the server.
  - **Please update the extension and PWA.** Once the server is updated, an extension or PWA that has not updated cannot leave a family or transfer ownership on accounts with a PIN or pattern, and the screen asks you to update. The extension updates itself, usually within a few hours; restarting the browser speeds it up. Reload the PWA page to update it.
- Accounts using a random verification code can no longer generate a code from a device that has been signed out. Families on a self-hosted server get this once the administrator updates the server.
  - Extension: if two devices sign in at almost the same moment, pressing "generate code" on one may sign it out and ask you to verify again. Switch the verification method to a PIN or pattern on the other device, go back to the signed-out one, press "Back", try again and sign in with the new PIN or pattern.
- Unused verification codes stop working once you leave or are removed from a family. Families on a self-hosted server get this once the administrator updates the server.
- After you switch account, family or server in another tab, a leave, delete or sign-in action that finishes late in an old tab no longer signs out or affects the new sign-in.
- Books you stop sharing no longer stay on your public shelf link. Families on a self-hosted server get this once the administrator updates the server.

# 繁體中文

## 問題修正

- 擴充功能：打開書櫃時被要求重新輸入 PIN 碼或圖形，輸入後隱藏的書不會再跑出來，也不必重新整理頁面。
- 擴充功能：收藏或隱藏沒能存到伺服器時，重新輸入 PIN 碼或圖形成功後會再存一次，存好後警告就會消失。
- 收藏或隱藏沒能存到伺服器時，關閉書櫃視窗會再存一次（PWA 沒有這個視窗，改在登出時存）。這次也失敗的話，變更就會遺失。
- 家庭書櫃的收藏或隱藏無法同步時，警告不會再叫你重新整理頁面，因為重新整理會失去還沒存好的變更。
- 擴充功能：同步途中確認切換伺服器時，這次同步會停下來並提示再同步一次，不會把舊伺服器讀到的書單寫到新伺服器。
- 移除帳戶途中出錯時，可以再按一次移除，把剩下的刪完；就算沒有再按，帳戶之後也會自動刪完，這時改變主意已經來不及。PIN 或圖形驗證會留到資料都刪完才移除。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 帳戶已經移除、畫面卻沒收到結果時，再按一次移除會直接完成，不會顯示失敗。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 移除帳戶後，還在進行的同步或設定變更不會把書單和公開連結帶回來；沒能馬上清掉的，通常約 30 分鐘內會清除。
  - 自架伺服器的管理者要更新伺服器並加上排程，請看 `worker/DEPLOY.md` 的「帳號刪除的定時清理」。
- 移除帳戶後約 2 分鐘內，同一個帳戶不能建立或加入家庭，畫面會請你稍後再試一次。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 擴充功能：加入家庭後第一次同步書單時，如果被移出或家庭已解散，會回到開始畫面並說明原因，不會進到打不開的家庭書櫃、只看到英文錯誤訊息。
- 擴充功能：離開、被移出或重新加入家庭後，不會再偶爾退回之前的樣子，例如又看到已經不在的家庭並多收到一次移出通知，或剛重新加入又得再加入一次。
- 擴充功能：需要重新輸入 PIN 碼才能登入時，可以直接打字，不必先點一下輸入框。
- 擴充功能：在兩個分頁都開著書櫃、其中一個已經離開家庭時，另一個分頁按下切換伺服器的「確認切換」不會切換，會請你關閉書櫃後重新開啟。

## 功能新增

- 同步封存書籍、自動同步頻率、「在購買頁顯示家人開放的書」和家庭書櫃按鈕大小這四項設定改成跟著帳號：在一個瀏覽器改過，其他瀏覽器下次打開書櫃就會套用，同步封存書籍也和 PWA 共用。使用自架伺服器的家庭，要等管理者更新伺服器後設定才會跟著帳號。
  - 購買頁的開關在別的瀏覽器打開後，這個瀏覽器還要授權一次，請到擴充功能的設定頁按「授權」。

## 安全與隱私

- 擴充功能：使用自架伺服器的家庭，在離開家庭、被移除、同步書單、儲存個人書櫃，或建立、加入家庭的途中，書單、收藏與隱藏清單、登入憑證和輸入的 PIN 碼或圖形都不會送到官方伺服器。
- 擴充功能：離開家庭、移除帳戶、轉移管理權和變更登入驗證方式的要求，只會送到你在那個畫面使用的伺服器。這只影響使用自架伺服器的家庭。
- 擴充功能和 PWA：用過自架伺服器的人，登入憑證只會送到發給它的那台伺服器，不會送到其他伺服器。
- 擴充功能：確認切換伺服器後會自動重新加入家庭，設了 PIN 或圖形驗證的人可能要再驗證一次。
- 擴充功能：用隨機驗證碼的人，切換伺服器前請先改成 PIN 或圖形驗證，否則可能無法重新加入家庭。
- 擴充功能：不在任何家庭的裝置，建立或加入家庭的要求只會送到官方伺服器、同步碼裡的伺服器，或管理者在這台裝置上指定的伺服器，不會送到之前那個家庭的伺服器。這只影響使用自架伺服器的家庭。
  - 自架伺服器的管理者：在還沒加入家庭的裝置上指定伺服器的方式改了，請看 `worker/DEPLOY.md` 第 9 節。
- 同一個帳號一小時內輸錯 10 次 PIN 碼、圖形或驗證碼後，就算輸入正確，也要等到下一個小時才能登入；登入還有效的裝置照常使用，擴充功能還能產生 QR Code 讓手機登入。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 用 QR Code 登入不會再把你用 PIN 碼或圖形登入的裝置登出；帳號的 5 個登入都是用 PIN 碼或圖形登入時，掃 QR Code 會改問 PIN 碼或圖形。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 確認目前的 PIN 碼或圖形時，每個登入每小時可以輸錯 5 次，別的登入輸錯不會擋住你換 PIN；用 QR Code 登入的裝置共用這 5 次。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 登入一直顯示「嘗試次數過多」時，管理者確認是本人後可以寄一次性的救援連結和臨時 PIN，把連結複製到平常用的瀏覽器開啟就能登入，登入後請馬上換掉 PIN。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 登入時輸錯 PIN 碼、圖形或驗證碼的每小時上限（10 次），以及確認目前的 PIN 碼或圖形時的上限（每個登入每小時 5 次），現在算得更可靠。日常使用感覺不到差別。
  - 自架伺服器的管理者要更新伺服器並加上一段新設定，做法在 `worker/DEPLOY.md` 的第 6 步；沒加也能照常運作，只是少了這項改善。
- 離開家庭或轉移管理權前，要先輸入目前的 PIN 碼或圖形，和移除帳戶一樣（設成驗證碼或不驗證的帳號不用）。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
  - **請更新擴充功能／PWA**：伺服器更新之後，還沒更新的擴充功能和 PWA，在設了 PIN 碼或圖形的帳號上無法離開家庭或轉移管理權，畫面會提示更新。擴充功能會自動更新，通常幾小時內完成，想快一點可以重新啟動瀏覽器；PWA 重新整理頁面就會更新。
- 用隨機驗證碼的帳號，裝置被登出後就不能再產生驗證碼。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
  - 擴充功能：兩台裝置幾乎同時登入時，其中一台按下產生驗證碼可能會被登出並要求重新驗證。這時請到另一台擴充功能把驗證方式改成 PIN 或圖形驗證，再回到被登出的那台按「返回」後再試一次，用新的 PIN 或圖形登入。
- 離開家庭或被移除後，之前產生、還沒用掉的驗證碼會一起失效。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
- 在另一個分頁換了帳號、家庭或伺服器後，舊分頁裡晚一步完成的離開家庭、移除帳戶或重新登入，不會讓新的登入被登出或受到影響。
- 取消開放的書不會再留在公開書櫃的連結上。使用自架伺服器的家庭，要等管理者更新伺服器才會生效。
